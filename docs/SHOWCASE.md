# Showcase

UnityTools AI Autopilot turns the Unity Editor into a local-first AI workspace.

## Demo Script

1. Open Unity.
2. Open `Window > UnityTools AI > Autopilot Chat`.
3. Ask: `Find realistic tree assets and group them by category.`
4. Ask: `Make a small forest using my real tree assets, not cubes.`
5. Watch semantic asset tools and batch placement calls appear in the panel.
6. Confirm real PolyHaven/Sketchfab/project assets are created in the Hierarchy.

## More Demo Prompts

```text
real relis realist tree assetlerini bul ve en iyi 10 tanesini goster
Create a rock field from real boulder assets.
Put 12 realistic trees from my assets around a circle.
Find character and weapon assets, grouped by folder.
Create a small campsite using real props from my project.
```

## Why It Is Useful

- It keeps the creative loop inside Unity.
- It avoids paid API keys by default through Ollama.
- It keeps tools explicit and inspectable.
- It searches the Unity asset database before creating primitives.
- It can be extended with more command handlers.
