# Showcase

UnityTools AI Autopilot turns the Unity Editor into a local-first AI workspace.

## Demo Script

1. Open Unity.
2. Open `Window > UnityTools AI > Autopilot Chat`.
3. Ask: `Create 5 cubes along the X axis and name them DemoCube_0 to DemoCube_4.`
4. Watch the tool calls appear in the panel.
5. Confirm objects are created in the Hierarchy.

## Why It Is Useful

- It keeps the creative loop inside Unity.
- It avoids paid API keys by default through Ollama.
- It keeps tools explicit and inspectable.
- It can be extended with more command handlers.
